# Bayview Community CU: overnight triage policy

Human-approved guidance that triage reads on every purchase. The morning review (a Factory Droid)
proposes edits to this file from last night's cases; an analyst approves each diff.
Hard rules live in code (server/gate.py) and this file cannot change them.

## General
- Hold first-time gift card, wire transfer and crypto purchases. These are the payment methods scammers demand.
- A category the member buys regularly, at similar amounts, is weak evidence on its own.
- Purchases late at night that break pattern are stronger evidence than the same purchase in daytime.
